MTH401 — Differential Equations — Midterm Revision Notes

Course: MTH401 Differential Equations, Virtual University of Pakistan (Fall 2026) Midterm scope: Lectures 1–22 (VU's announced midterm range for MTH401; final term = Lectures 23–45). Content follows the official VU MTH401 handouts, chapters 1–22. Paper style (past terms): mostly MCQs (1 mark) + subjective questions of 2, 3 and 5 marks. So formulas aur method ke steps dono yaad hone chahiye — sirf final answer nahi chalta.

Golden rule of this course: Pehle equation ko pehchano (identify its type), phir us type ka fixed method lagao. Aadha paper sirf sahi pehchan ka hai.

1. Basics & Classification (Lectures 1–2)

Term Meaning
Differential equation (DE) Equation containing derivatives of an unknown function
ODE Only ordinary derivatives — one independent variable
PDE Partial derivatives — two or more independent variables
Order Order of the highest derivative present
Degree Power of the highest derivative (after removing radicals/fractions in derivatives)
Linear DE y and its derivatives appear only in power 1, no products like y·y′, no sin y, e^y etc.
Explicit solution y written directly: y = φ(x)
Implicit solution Relation G(x, y) = 0 that defines y
General solution Contains arbitrary constants (as many as the order)
Particular solution Constants fixed by initial/boundary conditions
Singular solution A solution that cannot be obtained from the general solution for any value of the constants
IVP Initial-Value Problem: DE + conditions at one point, e.g. y(0) = 1
BVP Boundary-Value Problem: conditions at two different points

Worked example: For (dy/dx)² + 5y = x → order = 1 (highest derivative is dy/dx), degree = 2 (that derivative is squared). Equation is non-linear because of (y′)².

Exam points / traps: - Order hamesha highest derivative se hota hai, sab se bari power se nahi. - y′′ + (y′)³ + y = 0 is non-linear (because of (y′)³) — but its degree is 1, order is 2. - sin(y) or e^y makes a DE non-linear; sin(x) does NOT (x is the independent variable). - A solution is verified by substituting it back into the DE — common 2-mark question.

2. Separable Equations (Lecture 3)

Form: dy/dx = f(x)·g(y) — x aur y alag alag ho sakte hon.

Steps: 1. Separate: dy / g(y) = f(x) dx 2. Integrate both sides: ∫ dy/g(y) = ∫ f(x) dx + C 3. Apply initial condition if given.

Worked example: dy/dx = y/x → dy/y = dx/x → ln|y| = ln|x| + c → y = Cx.

Exam points / traps: - Constant ko hamesha akheer mein merge karo: ln C likh kar C ko akela karna asaan hota hai. - Dividing by g(y) may lose constant solutions where g(y) = 0 (e.g. y = 0) — mention them for full marks. - Agar integral mushkil ho to "implicit form" mein answer bhi acceptable hota hai.

3. Homogeneous Equations (Lecture 4)

Test: In dy/dx = F(x, y), if F(tx, ty) = F(x, y), the equation is homogeneous. Practically: every term has the same total degree (e.g. x² + xy + y²).

Method: Put y = vx (so dy/dx = v + x·dv/dx). The equation always becomes separable in v and x. Solve, then put v = y/x back.

Worked example: dy/dx = (x + y)/x. Put y = vx: v + x dv/dx = 1 + v → x dv/dx = 1 → v = ln|x| + C → y = x ln|x| + Cx.

Equations reducible to homogeneous: dy/dx = (ax + by + c)/(a₁x + b₁y + c₁) - Case 1 (a/a₁ = b/b₁, lines parallel): put v = ax + by (or a₁x + b₁y), equation becomes separable. - Case 2 (otherwise): shift origin — put x = X + h, y = Y + k, where (h, k) is the intersection point of the two lines (solve ah + bk + c = 0 and a₁h + b₁k + c₁ = 0). New equation in X, Y is homogeneous.

Exam points / traps: - dy/dx = v + x dv/dx likhna bhoolna sab se common ghalti hai — sirf v nahi likhte! - Case 1 vs Case 2 pehchanna: pehle a/a₁ aur b/b₁ check karo.

4. Exact Equations (Lecture 5)

Form: M(x, y) dx + N(x, y) dy = 0

Exactness test: ∂M/∂y = ∂N/∂x → exact.

Method: 1. F(x, y) = ∫ M dx (y ko constant samajh kar) + g(y) 2. ∂F/∂y = N se g′(y) nikaalo, integrate karke g(y) lagao. 3. Solution: F(x, y) = C.

Worked example: (2xy + y²) dx + (x² + 2xy) dy = 0. M_y = 2x + 2y = N_x ✓ exact. F = ∫(2xy + y²) dx = x²y + xy² + g(y); F_y = x² + 2xy + g′(y) = N → g′(y) = 0 → x²y + xy² = C.

Exam points / traps: - Pehle test, phir method — test fail ho to exact method mat lagao (integrating factor ki taraf jao, next section). - ∫N dy se bhi shuru kar sakte ho; dono se same F aata hai.

5. Integrating Factor (IF) Technique (Lecture 6)

Use when M dx + N dy = 0 is not exact. Multiply by μ so it becomes exact. Special cases:

Condition Integrating Factor
(M_y − N_x)/N is a function of x only, say f(x) μ = e^{∫ f(x) dx}
(N_x − M_y)/M is a function of y only, say g(y) μ = e^{∫ g(y) dy}
Equation homogeneous with xM + yN ≠ 0 μ = 1/(xM + yN)
Equation of form y·f(xy) dx + x·g(xy) dy = 0, xM − yN ≠ 0 μ = 1/(xM − yN)

Exam points / traps: - Sign ka khayal: pehle case mein M_y − N_x hai, doosre mein N_x − M_y — ulta karne se jawab ghalat ho jata hai. - IF se multiply karne ke baad exactness test dobara confirm karo, phir Section 4 wala method.

6. First-Order Linear Equations (Lecture 7)

Standard form: dy/dx + P(x)·y = Q(x)

Formula (yaad kar lo, har midterm mein aata hai): - Integrating factor: μ = e^{∫ P(x) dx} - Solution: y·μ = ∫ Q(x)·μ dx + C

Worked example: dy/dx + 2y = e^x. P = 2 → μ = e^{2x}. y·e^{2x} = ∫ e^x·e^{2x} dx = ∫ e^{3x} dx = e^{3x}/3 + C → y = e^x/3 + C e^{−2x}.

Exam points / traps: - Pehle equation ko standard form mein lao — dy/dx ka coefficient 1 hona chahiye. Agar 2(dy/dx) + ... ho to pehle 2 se divide karo, warna P ghalat niklega. - ∫P dx mein +C nahi likhte (IF ke liye aik hi constant kaafi hai).

7. Bernoulli Equations (Lecture 8)

Form: dy/dx + P(x)·y = Q(x)·yⁿ (n ≠ 0, 1)

Method: Divide by yⁿ, then substitute v = y^{1−n}. Equation becomes linear in v → solve by Section 6, then v ki jagah y^{1−n} wapas rakho.

Worked example: dy/dx + y = x y² (n = 2). v = y^{−1}, dv/dx = −y^{−2} dy/dx. Divide by y²: y^{−2}y′ + y^{−1} = x → −v′ + v = x → v′ − v = −x. IF = e^{−x}: v·e^{−x} = ∫ −x e^{−x} dx = (x + 1)e^{−x} + C → v = x + 1 + C e^x → y = 1/(x + 1 + C e^x).

Exam points / traps: - n = 0 ya n = 1 ho to Bernoulli nahi — woh already linear hai. - dv/dx ka negative sign (jab 1 − n negative ho) sab se common slip hai.

8. Applications of First-Order DEs (Lectures 9–12)

Application Model Key result
Population growth dP/dt = kP P = P₀ e^{kt}
Radioactive decay dN/dt = −kN N = N₀ e^{−kt}; half-life: t½ = ln 2 / k
Newton's Law of Cooling dT/dt = k(T − T_s) T = T_s + (T₀ − T_s) e^{kt}
Carbon dating Same decay law Age t = (1/k)·ln(N₀/N)
Logistic equation dP/dt = kP(1 − P/K) P = K / (1 + A e^{−kt}), A = (K − P₀)/P₀

Orthogonal Trajectories (OT): Curves that cut a given family of curves at right angles (90°). Method: (1) family ko differentiate karke dy/dx nikaalo, (2) constant eliminate karo, (3) dy/dx ki jagah −dx/dy (i.e. slope → −1/slope) rakho, (4) nayi DE solve karo.

Worked example (cooling): Body at 100°C in a room of 25°C: T = 25 + 75 e^{kt}. Agar 10 min baad T = 60 ho to e^{10k} = 35/75 → k = ln(7/15)/10 ≈ −0.0762. Phir kisi bhi time ka T nikaal sakte ho.

Exam points / traps: - Cooling mein T_s (surroundings ka temperature) minus karna mat bhoolo — sirf T par exponential nahi lagta. - Decay mein k negative aata hai; growth mein positive. Half-life wale sawal mein N = N₀/2 rakh kar t solve karte hain. - OT mein slope ka negative reciprocal lena hi poora concept hai — MCQ isi par banta hai.

9. Higher-Order Linear DEs — Theory (Lectures 13–14)

Standard form: aₙ(x) y⁽ⁿ⁾ + ... + a₁(x) y′ + a₀(x) y = g(x). If g(x) = 0 → homogeneous, warna non-homogeneous.

Existence & Uniqueness (IVP): If coefficients and g(x) are continuous on an interval I containing x₀, and aₙ(x) ≠ 0 on I, then the IVP has exactly one solution on I.

Linear dependence / independence: - Functions are linearly dependent if one is a constant multiple (or combination) of others; warna independent. - Wronskian: W(y₁, y₂) = | y₁ y₂ ; y₁′ y₂′ | = y₁y₂′ − y₂y₁′ - Criterion: If W ≠ 0 at some point of I → functions are linearly independent. If W = 0 for solutions of a linear DE → dependent. (Trap: W = 0 wali baat har functions ke liye converse true nahi hoti — handout khud note karta hai.)

Worked example: W(e^x, e^{2x}) = e^x·2e^{2x} − e^{2x}·e^x = e^{3x} ≠ 0 → linearly independent ✓.

Superposition Principle: If y₁, y₂ homogeneous equation ke solutions hain to y = c₁y₁ + c₂y₂ bhi solution hai.

General solution structure (sab se zyada poochha jane wala concept): - Homogeneous: y = y_c = c₁y₁ + c₂y₂ + ... + cₙyₙ (y₁..yₙ = fundamental set: n linearly independent solutions) - Non-homogeneous: y = y_c + y_p (y_p = koi aik particular solution)

Exam points / traps: - Fundamental set mein functions ki tadaad = equation ka order. - y_p mein arbitrary constants NAHI hote; y_c mein hote hain.

10. Reduction of Order (Lecture 15)

Agar aik solution y₁ maloom ho, doosra nikaalne ka tareeqa: y₂ = u(x)·y₁, jahan standard form y′′ + P(x)y′ + Q(x)y = 0 ke liye:

Formula: y₂ = y₁ ∫ [ e^{−∫ P(x) dx} / y₁² ] dx

Exam points / traps: - Formula lagane se pehle equation ko standard form mein lao (y′′ ka coefficient 1) — P wahi se milega. - Ye method tab hi jab aik solution diya gaya ho ya guess ho sakta ho (e.g. y₁ = e^x, x, sin x).

11. Homogeneous Equations with Constant Coefficients (Lecture 16) ⭐

Form: ay′′ + by′ + cy = 0 → Auxiliary (characteristic) equation: am² + bm + c = 0

Case Roots General Solution
1. Distinct real m₁ ≠ m₂ y = c₁ e^{m₁x} + c₂ e^{m₂x}
2. Repeated real m₁ = m₂ = m y = (c₁ + c₂ x) e^{mx}
3. Complex m = α ± iβ y = e^{αx} (c₁ cos βx + c₂ sin βx)

Worked examples: - y′′ − 3y′ + 2y = 0 → m² − 3m + 2 = 0 → m = 1, 2 → y = c₁e^x + c₂e^{2x} - y′′ − 2y′ + y = 0 → (m − 1)² = 0 → y = (c₁ + c₂x)e^x - y′′ + 4y = 0 → m = ±2i (α = 0, β = 2) → y = c₁ cos 2x + c₂ sin 2x

Higher order: Har root apna term deta hai; root k times repeat ho to x⁰, x¹, ..., x^{k−1} se multiply karte hain; complex pair α ± iβ repeat ho to x ki powers e^{αx}(cos βx, sin βx) ke saath bhi aati hain.

Exam points / traps: - Repeated root par x se multiply karna bhoolna = sab se common number-katai. - Complex roots mein e^{αx} factor mat bhoolo (α = 0 ho to khud hi 1 ho jata hai). - IVP diya ho to aakhir mein y aur y′ mein conditions laga kar c₁, c₂ solve karo.

12. Undetermined Coefficients — Superposition Approach (Lecture 17) ⭐

Sirf tab jab g(x) in mein se ho: constant, polynomial, e^{ax}, sin ax / cos ax, ya in ke sums/products.

Trial y_p table:

g(x) Trial y_p
Constant C A
xⁿ (polynomial) Aₙxⁿ + ... + A₁x + A₀ (full polynomial, same degree)
e^{ax} A e^{ax}
sin ax or cos ax A cos ax + B sin ax (DONO likhne hain)
xⁿ e^{ax} e^{ax} × (full polynomial of degree n)
e^{ax} sin bx / cos bx e^{ax}(A cos bx + B sin bx)

Duplication rule (sab se important): Agar trial y_p ka koi term y_c mein pehle se maujood ho, to poori trial ko x^s se multiply karo, jahan s = woh smallest power hai jis se duplication khatam ho jaye (s = root ki multiplicity).

Worked example: y′′ − 3y′ + 2y = e^{3x}. y_c = c₁e^x + c₂e^{2x}. Trial y_p = Ae^{3x}: 9A − 9A + 2A = 1 → A = 1/2 → y_p = ½e^{3x}. General: y = c₁e^x + c₂e^{2x} + ½e^{3x}. Lekin agar RHS e^x hota to trial Ae^x y_c se takrati — tab y_p = Axe^x lena parta.

Exam points / traps: - g(x) = ln x, tan x, 1/x, e^{x²} par ye method NAHI chalta — wahan Variation of Parameters lagta hai. - Sum wale g(x) ko hisson mein tor kar har hisse ka y_p alag banao (superposition). - Polynomial ke liye poora polynomial likho — sirf sab se bari power wala term nahi.

13. Annihilator Operator Approach (Lectures 18–19)

D = d/dx operator. Annihilator = woh operator jo kisi function ko zero kar de. Equation ko operator form mein likh kar dono taraf annihilator lagao → homogeneous equation banti hai jis se y_p ki form mil jati hai (constants phir original equation mein rakh kar).

Function Annihilator
xⁿ D^{n+1}
e^{ax} (D − a)
xⁿ e^{ax} (D − a)^{n+1}
sin ax / cos ax D² + a²
e^{ax} sin bx / cos bx (D − a)² + b² = D² − 2aD + (a² + b²)

Exam points / traps: - xⁿ ka annihilator D^{n+1} hai, Dⁿ nahi (power hamesha aik zyada). - Ye approach asal mein Section 12 ki duplication rule ki wajah samjhata hai — dono ka result same aata hai.

14. Variation of Parameters (Lectures 20–21) ⭐

Kab lagta hai: Jab g(x) koi bhi function ho (ln x, tan x, sec x, 1/x...) — Undetermined Coefficients fail ho jaye to yehi rasta hai. Pehle y_c zaroor nikaalo.

Second-order formulas — for y′′ + P(x)y′ + Q(x)y = g(x) (standard form lazmi), with y_c = c₁y₁ + c₂y₂ and W = Wronskian of y₁, y₂:

  • y_p = u₁y₁ + u₂y₂
  • u₁′ = −y₂ g(x) / W
  • u₂′ = +y₁ g(x) / W
  • u₁, u₂ integrate karke nikaalo (integration constants y_p mein nahi lete).

Worked example: y′′ − 2y′ + y = e^x / x. y₁ = e^x, y₂ = xe^x, W = e^{2x}, g = e^x/x. u₁′ = −(xe^x)(e^x/x)/e^{2x} = −1 → u₁ = −x. u₂′ = (e^x)(e^x/x)/e^{2x} = 1/x → u₂ = ln|x|. y_p = −x e^x + x e^x ln|x| → −xe^x wala hissa y_c mein already hai, effective y_p = x e^x ln|x|. General solution: y = (c₁ + c₂x)e^x + x e^x ln|x|.

Higher order: Same idea — har u_k′ Wronskian determinants ke ratio se milta hai (W_k / W), jahan W_k mein k-th column ko (0, 0, ..., g) se replace karte hain.

Exam points / traps: - Equation ko standard form (y′′ ka coefficient 1) mein kiye baghair g(x) ghalat parhoge — sab se bari ghalti. - u₁′ mein negative sign hai, u₂′ mein positive — ulta karna aam slip hai. - y_p ke liye u integrate karte waqt +C nahi lagate (woh y_c mein pehle se hai).

15. Applications of Second-Order DEs — Spring–Mass Motion (Lecture 22, start)

Model: m x′′ + c x′ + k x = F(t) — m = mass, c = damping constant, k = spring constant (Hooke's Law: F = −kx).

Free motion (F = 0) ki pehchan discriminant c² − 4mk se:

Condition Type Behaviour
c² − 4mk > 0 Overdamped Slow return, no oscillation
c² − 4mk = 0 Critically damped Fastest return without oscillation
c² − 4mk < 0 Underdamped Oscillations with decreasing amplitude

Undamped (c = 0): x′′ + ω²x = 0 with ω² = k/m → Simple Harmonic Motion, period T = 2π/ω.

Exam points / traps: - Auxiliary equation yahan mλ² + cλ + k = 0 banti hai — Section 11 wale hi teen cases hain, bas naam badal jate hain. - Weight W = mg se mass nikaalte hain (English system mein m = W/g, g = 32 ft/s²) — units wala sawal aata hai.
