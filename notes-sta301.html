Topic 1 — Introduction: Data, Variables, Measurement Scales (Lectures 1–2)

Key ideas - Statistics: science of collecting, organising, analysing and interpreting data to draw conclusions. Two branches: Descriptive (summarise data — tables, graphs, averages) and Inferential (sample se population ke baare mein conclusion). - Population = complete set under study; Sample = a part of it. Parameter = population ki value (μ, σ); Statistic = sample ki value (x̄, s). - Observation = one recorded value; Variable = characteristic that changes from unit to unit. - Types of variables: Qualitative (categorical: gender, colour) vs Quantitative (numerical). Quantitative → Discrete (countable: number of students — beech wali value nahi ho sakti) vs Continuous (measurable: height, weight — koi bhi value ho sakti hai). - Measurement scales (sab se zyada MCQ yahin se aata hai): 1. Nominal — sirf naam/labels (gender, blood group). Koi order nahi. 2. Ordinal — order hai magar gap barabar nahi (grades A/B/C, ranks). 3. Interval — barabar gap, magar true zero nahi (temperature in °C, calendar year). 20°C is NOT "twice as hot" as 10°C. 4. Ratio — barabar gap + true zero (height, weight, income). Ratios meaningful hain. - Error of measurement = observed value − true value. Relative error = absolute error ÷ true value. - Data collection / sampling: Census = poori population; Sampling = hissa. Random sampling types: Simple random (har unit ko barabar chance), Stratified (population ko groups/strata mein baant kar har group se random), Systematic (har k-th unit), Cluster (groups chun kar un ke andar sab).

Exam points / traps - Temperature °C = interval, Kelvin = ratio (true zero hai). - "Number of cars" discrete hai; "speed of cars" continuous. - Statistic vs parameter ki pehchan: sample → statistic, population → parameter.

Topic 2 — Presentation of Data: Frequency Distributions & Graphs (Lectures 3–5)

Key ideas - Raw data = unorganised data. Pehla step hamesha organisation hai. - Frequency distribution: values/classes ke saath un ki counts (frequencies). Discrete variable ke liye simple tally table; continuous ke liye class intervals. - Class interval ki terms: class limits (e.g. 10–20), class boundaries (9.5–20.5 — jab gap ho to half gap adjust), midpoint/mark x = (lower + upper)/2, class width h = upper boundary − lower boundary. - Number of classes (Sturges' rule): k = 1 + 3.322 log₁₀N. Class width ≈ Range ÷ k, jahan Range = largest − smallest. - Relative frequency = f ÷ N (sab ka sum = 1). Percentage frequency = relative × 100. - Cumulative frequency: "less than" type (uper ki taraf jama hoti hai) aur "more than" type. - Graphs: - Bar chart — categories ke liye, bars ke beech gap hota hai. - Histogram — continuous data, bars mile hue (no gaps), area ∝ frequency. - Frequency polygon — midpoints par points jod kar line; histogram ke upar bhi banta hai. - Frequency curve — smoothed polygon. - Ogive — cumulative frequency curve; do ogives ("less than" + "more than") jahan milti hain, wahan se median milta hai. - Pie chart — har slice ka angle = (f ÷ N) × 360°. - Stem-and-leaf — data ko stem (pehle digits) aur leaf (aakhri digit) mein; asal values bhi mehfooz rehti hain. - Frequency curve shapes: symmetric (bell), positively skewed (lambi tail right ki taraf), negatively skewed (tail left), U-shaped, J-shaped.

Worked example: 40 students, class 20–30 ki frequency 8 hai → relative frequency = 8/40 = 0.20; pie chart angle = 0.20 × 360° = 72°.

Exam points / traps - Histogram mein bars ke beech gap nahi hota; bar chart mein hota hai. - Skewness ki tail: positive skew = tail right side (mean sab se bara hota hai — Topic 5 dekho). - Ogive hamesha cumulative frequency se banti hai, simple frequency se nahi.

Topic 3 — Measures of Central Tendency (Lectures 6–9) ⭐ sab se important

Central tendency = poore data ki ek representative value (average). Har average ke apne formulas hain — sab yaad karne hain.

3.1 Mode

  • Sab se zyada repeat hone wali value. Data mein 0, 1 ya zyada modes ho sakte hain (unimodal, bimodal).
  • Grouped data: Mode = L + [(f₁ − f₀) ÷ (2f₁ − f₀ − f₂)] × h, jahan L = modal class ki lower boundary, f₁ = modal class ki frequency, f₀ = us se pehli class ki, f₂ = us ke baad wali class ki.

3.2 Arithmetic Mean (AM)

  • Ungrouped: x̄ = Σx ÷ n
  • Grouped: x̄ = Σfx ÷ Σf (x = class midpoint)
  • Short-cut / step-deviation: x̄ = A + (Σfd ÷ N) × h, jahan d = (x − A) ÷ h, A = assumed mean.
  • Weighted mean: x̄ = Σwx ÷ Σw (weights = importance, e.g. credit hours in GPA).
  • Combined mean (do groups): x̄ = (n₁x̄₁ + n₂x̄₂) ÷ (n₁ + n₂)
  • Properties: Σ(x − x̄) = 0 (deviations ka sum hamesha zero); har value change ho to mean bhi change hota hai; extreme values se sab se zyada affect hota hai.

3.3 Median

  • Data ko sort karke beech wali value; data ko do barabar hisson mein baantti hai.
  • Ungrouped: odd n → ((n+1)/2)-th value; even n → n/2-th aur (n/2 + 1)-th values ka average.
  • Grouped: Median = L + [((N/2) − C) ÷ f] × h, jahan C = median class se pehle ki cumulative frequency, f = median class ki frequency.
  • Open-ended distribution (pehli/aakhri class khuli, e.g. "60 and above") mein mean nahi nikal sakta (midpoints nahi milte) — median aur mode hi use hote hain. Ye classic exam point hai.
  • Median extreme values se affect nahi hota → skewed data ke liye best average.

3.4 Empirical Relation (moderately skewed data ke liye)

Mode = 3 × Median − 2 × Mean — teeno mein se koi do maloom hon to teesra nikal aata hai. Ye observation par based hai, exact law nahi.

3.5 Quantiles — Quartiles, Deciles, Percentiles

  • Quartiles Q₁, Q₂ (= median), Q₃ data ko 4 barabar hisso mein; Deciles 10 mein (D₁…D₉); Percentiles 100 mein (P₁…P₉₉).
  • Grouped formula (Q₁ ki misaal): Q₁ = L + [((N/4) − C) ÷ f] × h. Isi tarah Q₃ ke liye 3N/4, Dₖ ke liye kN/10, Pₖ ke liye kN/100 use hota hai.
  • Quantiles ko graph par ogive se bhi locate kiya jata hai.

3.6 Geometric Mean (GM) & Harmonic Mean (HM)

  • GM = (x₁ · x₂ · … · xₙ)^(1/n), ya antilog of (Σ log x ÷ n). Rates, ratios aur percentage changes ke average ke liye (growth rates, index numbers).
  • HM = n ÷ Σ(1/x). Speed ke average ke liye jab distance barabar ho (jaana aana same route).
  • Relation: AM ≥ GM ≥ HM (barabari sirf jab sab values barabar hon).

3.7 Kaunsa average kab? (favourite MCQ area)

Situation Best average
Aam numerical data, further calculation chahiye Mean
Skewed data / open-ended classes Median
Sab se common item (shoe size, shirt size stock) Mode
Growth rates, ratios, % change GM
Average speed (equal distances) HM
Qualitative "most typical" Mode

Worked example 1: Data: 4, 6, 6, 8, 10, 12, 14 → Σx = 60, n = 7 → Mean = 60/7 = 8.57; sorted data ka beech = Median 8; Mode = 6. Check empirical relation: 3(8) − 2(8.57) = 6.86 ≈ 6 (lagbhag — empirical hai, exact nahi).

Worked example 2 (grouped median): Classes 0–10(5), 10–20(8), 20–30(12), 30–40(6), 40–50(4). N = 35, N/2 = 17.5 → median class 20–30 (C = 13, f = 12). Median = 20 + [(17.5 − 13)/12] × 10 = 20 + 3.75 = 23.75.

Worked example 3 (HM): Car 60 km @ 30 km/h jaati hai, wapas 60 km @ 60 km/h → average speed = HM = 2 ÷ (1/30 + 1/60) = 2 ÷ 0.05 = 40 km/h (45 nahi! — ye classic trap hai).

Exam points / traps - Median ke formula mein N/2 use hota hai, (N+1)/2 nahi (woh ungrouped position ke liye hai). - Mode wala data "bimodal" ho sakta hai — mode hamesha unique nahi hota. - Mean har value use karta hai, is liye ek bohat bari/chhoti value poora mean kharab kar deti hai.

Topic 4 — Measures of Dispersion (Lectures 10–11) ⭐

Dispersion = data kitna phaila hua hai. Do data sets ka mean same ho sakta hai magar phailaav mukhtalif — is liye average akela kaafi nahi.

Absolute measures (asal units mein: marks, kg) vs Relative measures (unit-free coefficients — do mukhtalif data sets ka comparison inhi se hota hai).

4.1 Range

  • Range = Largest − Smallest. Coefficient of range = (L − S) ÷ (L + S).
  • Sab se asan, magar sirf 2 values use karta hai → sab se kam reliable.

4.2 Quartile Deviation (QD)

  • QD = (Q₃ − Q₁) ÷ 2 (ye semi-interquartile range hai). Interquartile range IQR = Q₃ − Q₁.
  • Coefficient of QD = (Q₃ − Q₁) ÷ (Q₃ + Q₁).

4.3 Mean Deviation (MD)

  • MD = Σ|x − x̄| ÷ n (mean se) ya Σ|x − Median| ÷ n. Absolute values is liye ke deviations ka sum warna zero ho jata hai.
  • Coefficient of MD = MD ÷ Mean (ya MD ÷ Median, jis se calculate kiya ho).

4.4 Variance & Standard Deviation ⭐ sab se important

  • Population variance: σ² = Σ(x − μ)² ÷ N; Sample variance: s² = Σ(x − x̄)² ÷ (n − 1)
  • Short-cut: σ² = (Σx² ÷ N) − μ²; grouped: σ² = (Σfx² ÷ N) − x̄²
  • Standard deviation = √variance (positive root). Variance units ka square hota hai, SD asal units mein wapas aa jata hai.
  • Coefficient of Variation: CV = (s ÷ x̄) × 100% — consistency compare karne ke liye. CV chhota = zyada consistent / kam risky.

Worked example: Data: 2, 4, 6, 8, 10. Mean = 6. Squared deviations: 16 + 4 + 0 + 4 + 16 = 40. - Population: σ² = 40/5 = 8 → σ = 2.83 - Sample: s² = 40/4 = 10 → s = 3.16; CV = (3.16/6) × 100 = 52.7%

Exam points / traps - Sample variance mein denominator n − 1 hai, population mein N. Paper mein data "sample" kaha gaya ho to n − 1. - Do teams/shares ki consistency compare karni ho to SD nahi, CV compare karo (units aur means mukhtalif ho sakte hain). - SD hamesha ≥ 0 hota hai; sab values barabar hon to SD = 0. - Variance kabhi negative nahi ho sakti.

Topic 5 — Chebyshev, Empirical Rule, Skewness, Kurtosis & Moments (Lectures 12–14)

5.1 Chebyshev's Theorem (kisi bhi shape ke data ke liye)

Kisi bhi data set mein, k > 1 ke liye, kam az kam (1 − 1/k²) hissa values mean se k standard deviations ke andar hota hai, i.e. interval (x̄ − ks, x̄ + ks) mein. - k = 2 → kam az kam 1 − 1/4 = 75% - k = 3 → kam az kam 1 − 1/9 = 88.9% - k = 1 par theorem kuch nahi kehta (0%) — ye trap hai.

5.2 Empirical Rule (sirf bell-shaped / symmetric data ke liye)

  • x̄ ± 1s ke andar ≈ 68%
  • x̄ ± 2s ke andar ≈ 95%
  • x̄ ± 3s ke andar ≈ 99.7% (handout: "practically all") Farq yaad rakho: Chebyshev = har distribution, guarantee "at least"; Empirical = sirf mound-shaped/symmetric, values "approximately".

5.3 Five-Number Summary & Box Plot

Five numbers: Minimum, Q₁, Median, Q₃, Maximum. Inhi se box-and-whisker plot banta hai: box Q₁ se Q₃ tak (beech mein median ki line), whiskers min aur max tak. Box plot se skewness bhi nazar aata hai (median box ke kis taraf zyada qareeb hai).

5.4 Skewness (distribution ki asymmetry)

  • Symmetric: Mean = Median = Mode, skewness = 0.
  • Positively skewed: tail right ki taraf; Mean > Median > Mode.
  • Negatively skewed: tail left ki taraf; Mean < Median < Mode.
  • Pearson's coefficient: Sk = (Mean − Mode) ÷ SD; doosri soorat: Sk = 3(Mean − Median) ÷ SD (range −3 se +3).
  • Bowley's coefficient (quartiles par): Sk = (Q₃ + Q₁ − 2·Median) ÷ (Q₃ − Q₁) (range −1 se +1).

5.5 Moments & Kurtosis

  • r-th moment about the mean: μᵣ = Σf(x − x̄)ʳ ÷ N. Note: μ₁ = 0 hamesha; μ₂ = variance.
  • Moments about arbitrary origin A: μ′ᵣ = Σf(x − A)ʳ ÷ N. Conversion: μ₂ = μ′₂ − (μ′₁)²; μ₃ = μ′₃ − 3μ′₂μ′₁ + 2(μ′₁)³; μ₄ = μ′₄ − 4μ′₃μ′₁ + 6μ′₂(μ′₁)² − 3(μ′₁)⁴.
  • Moment ratios: β₁ = μ₃² ÷ μ₂³ (skewness ki measure; γ₁ = √β₁ = μ₃ ÷ μ₂^1.5, sign μ₃ wala). β₂ = μ₄ ÷ μ₂² (kurtosis — curve kitni nok-daar/flat hai).
  • Kurtosis: β₂ = 3 → Mesokurtic (normal jaisi); β₂ > 3 → Leptokurtic (zyada nok-daar); β₂ < 3 → Platykurtic (flat). Excess kurtosis γ₂ = β₂ − 3.
  • Kelly's percentile coefficient of kurtosis: k = [(Q₃ − Q₁) ÷ 2] ÷ (P₉₀ − P₁₀); normal curve ke liye ≈ 0.263.
  • Sheppard's corrections (grouping error theek karne ke liye, sirf continuous distribution jo dono ends par zero par taper ho, barabar class intervals hon):
  • μ₂ (corrected) = μ₂ − h²/12
  • μ₃ (corrected) = μ₃ (koi tabdeeli nahi)
  • μ₄ (corrected) = μ₄ − (h²/2)μ₂ + 7h⁴/240
  • Highly skewed distribution ya unequal intervals par apply nahi hotay.

Worked example (Chebyshev): Mean = 50, SD = 5. Interval 40–60 matlab k = 2 → kam az kam 75% students ke marks 40 aur 60 ke darmiyan hain — chahe distribution kisi bhi shape ki ho.

Exam points / traps - Positive skew mein mean sab se bara hota hai (tail mean ko apni taraf kheenchti hai). - β₂ = 3 benchmark hai — is se zyada/kam hi kurtosis ki pehchan hai. - Sheppard mein μ₃ change nahi hota — favourite MCQ.

Topic 6 — Regression & Correlation (Lecture 15) — short but examinable

  • Regression: ek variable (Y) ki value doosre (X) se predict karna. Line: Ŷ = a + bX, jahan b = Σ(x − x̄)(y − ȳ) ÷ Σ(x − x̄)² aur a = ȳ − b·x̄. Line hamesha point (x̄, ȳ) se guzarti hai.
  • Standard error of estimate: S = √[ Σ(y − Ŷ)² ÷ (n − 2) ] — predictions kitni bikhri hui hain asal values se; chhota S = behtar fit.
  • Correlation (r): do variables ke linear taluq ki strength aur direction: r = Σ(x − x̄)(y − ȳ) ÷ √[Σ(x − x̄)² · Σ(y − ȳ)²], hamesha −1 ≤ r ≤ +1.
  • r = +1 perfect positive; r = −1 perfect negative; r = 0 koi linear taluq nahi (non-linear ho sakta hai!).
  • Traps: Correlation ≠ causation (taluq hai matlab wajah hai — zaroori nahi). r sirf linear relation measure karta hai. Regression ki do lines hoti hain (Y on X, X on Y); un ke slopes ka product = r².

Topic 7 — Probability Basics & Counting Rules (Lectures 16–19) ⭐

7.1 Basic language

  • Random experiment = jis ka result pehle se pakka na ho (coin toss, dice). Sample space S = tamam possible outcomes ka set. Event = sample space ka subset.
  • Mutually exclusive events: aik saath nahi ho sakte (A ∩ B = ∅). Exhaustive: mila kar poora sample space cover kar dein. Equally likely: har outcome ka chance barabar.
  • Set notation: A ∪ B (A ya B), A ∩ B (dono), A′ / Ā (A nahi — complement), ∅ (empty/impossible), S (sure event).

7.2 Counting rules (probability se pehle ye pakkay karo)

  • Multiplication rule of counting: pehla kaam m tareeqon se, doosra n tareeqon se → dono mila kar m × n tareeqay.
  • Permutation (order matter karta hai): ⁿPᵣ = n! ÷ (n − r)! — e.g. race mein 1st/2nd positions.
  • Combination (order matter NAHI karta): ⁿCᵣ = n! ÷ [r!(n − r)!] — e.g. committee chunna. Note: ⁿCᵣ = ⁿCₙ₋ᵣ.
  • n! = n × (n−1) × … × 1; 0! = 1.

Worked example: 10 students mein se 3 ki committee: C(10,3) = 120. Agar unhi 3 ko President/VP/Secretary banana ho (order matter): P(10,3) = 720.

7.3 Definitions of probability

  • Classical (a priori): P(A) = favourable outcomes ÷ total equally-likely outcomes = m ÷ n. Sirf jab outcomes equally likely hon.
  • Relative frequency (empirical): P(A) ≈ (times A occurred) ÷ (total trials), jab trials bohat zyada hon (limit).
  • Axiomatic: (i) 0 ≤ P(A) ≤ 1; (ii) P(S) = 1; (iii) mutually exclusive events ke liye P(A ∪ B) = P(A) + P(B).

7.4 Basic laws

  • Complement rule: P(A′) = 1 − P(A). "At least one" wale sawal hamesha is se hal hote hain.
  • Addition theorem (general): P(A ∪ B) = P(A) + P(B) − P(A ∩ B)
  • Mutually exclusive hon to: P(A ∪ B) = P(A) + P(B).
  • Impossible event ki probability 0; sure event ki 1.

Worked example ("at least one"): Coin 3 dafa toss — kam az kam ek Head ki probability = 1 − P(no head) = 1 − (1/2)³ = 1 − 1/8 = 7/8.

Exam points / traps - P(A ∪ B) mein P(A ∩ B) minus karna mat bhoolna — warna overlap do dafa count ho jata hai. - "At least one" dekha → seedha complement rule. - Permutation vs combination: positions/ranks/arrangement = P; selection/group = C.

Topic 8 — Conditional Probability, Multiplication Theorem & Independence (Lectures 20–21) ⭐

  • Conditional probability: B pehle ho chuka ho, to A ki probability: P(A|B) = P(A ∩ B) ÷ P(B), (P(B) > 0). Asan alfaaz mein: sample space chhota ho gaya — ab sirf B wali duniya mein hisaab hai.
  • Multiplication theorem: P(A ∩ B) = P(A) · P(B|A) = P(B) · P(A|B) — "aur" (dono) wale sawalon ka formula.
  • Independent events: ek ke hone se doosre ki probability nahi badalti: P(A|B) = P(A), aur P(A ∩ B) = P(A) · P(B).
  • Dependent events: with replacement vs without replacement — baghair wapas rakhe doosri draw ki probability badal jati hai (dependent).
  • Marginal probability / Law of total probability: agar A₁, A₂, …, Aₖ sample space ki partition hain, to P(B) = Σ P(Aᵢ) · P(B|Aᵢ) — Bayes' theorem ki buniyaad yahi hai.

Worked example: Bag mein 4 red, 6 green balls. Do balls baghair replacement ke: P(dono red) = (4/10) × (3/9) = 12/90 = 2/15 ≈ 0.133. (Replacement ke saath hota to (4/10)² = 0.16 — farq dependent/independent ka hai.)

Exam points / traps ⭐ sab se mashhoor trap: - Mutually exclusive ≠ Independent! Mutually exclusive hon to P(A ∩ B) = 0, jabke independent hon to P(A ∩ B) = P(A)P(B) (jo aam tor par 0 nahi hota). Dono aik saath sirf tab ho sakte hain jab kisi event ki probability 0 ho. - P(A|B) aur P(B|A) mukhtalif hain — formula mein numerator same, denominator badal jata hai.

Topic 9 — Bayes' Theorem (Lecture 22) ⭐⭐ numerical pakka aata hai

Idea: Result (effect) maloom hai, wajah (cause) ki probability nikalni hai — probability ko "ulta" karna.

Formula: Agar A₁, …, Aₖ causes (partition) hain aur B observed event hai:

P(Aᵢ|B) = [ P(Aᵢ) · P(B|Aᵢ) ] ÷ [ Σⱼ P(Aⱼ) · P(B|Aⱼ) ]

  • P(Aᵢ) = prior probability (pehle se maloom); P(Aᵢ|B) = posterior (evidence ke baad updated).
  • Denominator = total probability of B (Topic 8 wala formula).

Worked example (factory — VU ki favourite type): Factory mein Machine A total production ka 60% banati hai, jin mein 2% defective hain. Machine B 40% banati hai, 3% defective. Ek item defective mila — probability woh Machine A ka hai? - P(A) = 0.60, P(D|A) = 0.02 → 0.60 × 0.02 = 0.012 - P(B) = 0.40, P(D|B) = 0.03 → 0.40 × 0.03 = 0.012 - P(A|D) = 0.012 ÷ (0.012 + 0.012) = 0.50

Hal karne ka tareeqa (table bana lo): har cause ke liye prior × likelihood ka column banao, sum karo, phir jis cause ki probability poochhi hai usay sum se divide kar do. Ghalti ki gunjaish khatam ho jati hai.

Exam points / traps - Sawal mein "given that defective hai, kis machine se aaya hoga" — yehi pehchan hai Bayes ki. - Denominator mein sab causes shamil karna mat bhoolna.

Topic 10 — Discrete Random Variables & Probability Distributions (Lecture 22) ⭐

  • Random variable (RV): har outcome ko number dene wala function. Discrete RV = ginay ja sakne wali values (0, 1, 2, …); continuous = kisi interval mein koi bhi value (woh Lecture 23+ hai, midterm se bahir).
  • Probability distribution / pmf f(x) ki 2 shartein: (i) f(x) ≥ 0 har x ke liye; (ii) Σf(x) = 1. Koi value in ke khilaf jaye to woh valid distribution nahi.
  • Distribution function (CDF): F(x) = P(X ≤ x) — step function hoti hai; F(x) = Σ over all values ≤ x. Aur P(a < X ≤ b) = F(b) − F(a).
  • Mean of a discrete RV (= expected value): μ = E(X) = Σ x·f(x)
  • Variance: σ² = E(X²) − [E(X)]², jahan E(X²) = Σ x²·f(x). (Doosri soorat: σ² = Σ (x − μ)² f(x) — dono same, pehli wali zyada fast hai.)
  • SD = √σ²; CV = (σ ÷ μ) × 100% (discrete distribution ke liye bhi wahi CV wala usool).

Worked example: 2 coins toss, X = number of Heads. Distribution: X=0 → 1/4, X=1 → 1/2, X=2 → 1/4. - E(X) = 0(1/4) + 1(1/2) + 2(1/4) = 1 - E(X²) = 0 + 1(1/2) + 4(1/4) = 1.5 → Var = 1.5 − 1² = 0.5, SD = 0.707 - F(1) = P(X ≤ 1) = 1/4 + 1/2 = 0.75

Exam points / traps - "k ki value nikalo taake ye valid distribution ho" → Σf(x) = 1 laga kar k nikalta hai. Pakka aane wala sawal hai. - E(X) hamesha X ki koi asal value ho — zaroori nahi (E = 1.5 heads ho sakta hai, aadha head nahi hota). - Var ke shortcut formula mein [E(X)]² minus karna mat bhoolna.

Central tendency - Mean: x̄ = Σx/n | grouped: Σfx/N | step-deviation: A + (Σfd/N)·h - Weighted mean: Σwx/Σw | Combined mean: (n₁x̄₁ + n₂x̄₂)/(n₁ + n₂) - Median (grouped): L + [(N/2 − C)/f]·h - Mode (grouped): L + [(f₁ − f₀)/(2f₁ − f₀ − f₂)]·h - Empirical relation: Mode = 3·Median − 2·Mean - Quartile (grouped): Q₁ = L + [(N/4 − C)/f]·h (Q₃ → 3N/4; Dₖ → kN/10; Pₖ → kN/100) - GM = (Πx)^(1/n) | HM = n/Σ(1/x) | AM ≥ GM ≥ HM

Dispersion - Range = L − S; Coeff = (L − S)/(L + S) - QD = (Q₃ − Q₁)/2; Coeff of QD = (Q₃ − Q₁)/(Q₃ + Q₁) - MD = Σ|x − x̄|/n; Coeff of MD = MD/Mean - Variance: σ² = Σ(x − μ)²/N (population) | s² = Σ(x − x̄)²/(n − 1) (sample) | shortcut: Σx²/N − x̄² - SD = √variance | CV = (SD/Mean) × 100% - Chebyshev: within k SD ≥ (1 − 1/k²) | Empirical rule: 68% / 95% / 99.7% (1s/2s/3s, bell-shaped only)

Shape (skewness, kurtosis, moments) - Pearson Sk = (Mean − Mode)/SD = 3(Mean − Median)/SD - Bowley Sk = (Q₃ + Q₁ − 2Median)/(Q₃ − Q₁) - μᵣ = Σf(x − x̄)ʳ/N; μ₁ = 0; μ₂ = variance - β₁ = μ₃²/μ₂³; γ₁ = μ₃/μ₂^1.5 | β₂ = μ₄/μ₂² (kurtosis: =3 meso, >3 lepto, <3 platy) - Sheppard: μ₂ corr = μ₂ − h²/12; μ₃ same; μ₄ corr = μ₄ − (h²/2)μ₂ + 7h⁴/240

Regression & correlation - Ŷ = a + bX; b = Σ(x − x̄)(y − ȳ)/Σ(x − x̄)²; a = ȳ − b·x̄ - r = Σ(x − x̄)(y − ȳ)/√[Σ(x − x̄)²Σ(y − ȳ)²]; −1 ≤ r ≤ 1 - S.E. of estimate = √[Σ(y − Ŷ)²/(n − 2)]

Counting & probability - Multiplication rule: m × n | ⁿPᵣ = n!/(n − r)! | ⁿCᵣ = n!/[r!(n − r)!] - P(A) = m/n (classical) | P(A′) = 1 − P(A) - P(A ∪ B) = P(A) + P(B) − P(A ∩ B) - P(A|B) = P(A ∩ B)/P(B) | P(A ∩ B) = P(A)·P(B|A) - Independent: P(A ∩ B) = P(A)·P(B) - Total probability: P(B) = Σ P(Aᵢ)·P(B|Aᵢ) - Bayes: P(Aᵢ|B) = P(Aᵢ)·P(B|Aᵢ) / Σ P(Aⱼ)·P(B|Aⱼ)

Discrete random variable - Valid pmf: f(x) ≥ 0, Σf(x) = 1 | F(x) = P(X ≤ x) - E(X) = Σx·f(x) | Var(X) = E(X²) − [E(X)]² | SD = √Var | CV = (σ/μ) × 100%
